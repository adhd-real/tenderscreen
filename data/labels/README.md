# data/labels

Hand-labelled answers for the evaluation harness: one `<document id>.json` per
document, named like the document in `data/manual/` without its extension
(`pwd_award_2026_17.pdf` → `pwd_award_2026_17.json`).

Start from `_template.json` (files starting with `_` are ignored by the
evaluator). The full step-by-step guide is [docs/labelling.md](../../docs/labelling.md).
